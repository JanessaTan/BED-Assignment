IMAGE PLACEHOLDER GUIDE

This project intentionally does not include downloaded images.

To add your own media:
1. Put licensed image files in this img folder.
2. Update the matching image path in the relevant JavaScript data.
3. Add the creator, source URL, licence, and access date to html/credit.html.
4. Keep descriptive alt text for accessibility.

Suggested filenames:
- hawker-placeholder.jpg
- clementi-hawker.jpg
- bedok-hawker.jpg
- food-placeholder.jpg

The CSS placeholder panels keep the layout presentable when an image is missing.
